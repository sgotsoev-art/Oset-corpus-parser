

## Постановка задачи
Дана таблица фразеологизмов на осетинском языке. Для каждого фразеологизма необходимо найти источники с сайта корпуса осетинского языка, где он встречается, разбить источники по подкорпусам и для каждого подкорпуса
посчитать, с какой частотой в нем встречается данный фразеологизм.

На выходе получаем отчетную таблицу:
- **Лист 1** — для каждого фразеологизма указан подкорпус, источник и максимально широкий контекст, в котором фразеологизм упоминается
- **Лист 2** — статистика: с какой частотой фразеологизм встречается в каждом из подкорпусов и сколько упоминаний всего

## Этапы работы
1. **`lemmatr.py`** — скрипт для выборки первых двух слов из фразеологизма и их перевода в начальную форму (лемму) → получение таблицы с леммами фразеологизмов
2. **`testpars.py`** — скрипт для прогона одного фразеологизма в одном подкорпусе (отладка)
3. **`final_parser.py`** — основной скрипт, который пропарсил сайт и прогнал все фразеологизмы через все подкорпуса
4. **`chastota.py`** — скрипт для подсчёта частоты упоминаний фразеологизмов в различных подкорпусах

## Этапы работы скрипа 'lemmatr.py'

Перед запуском основного скрипта необходимо было получить леммы (начальные формы) первых двух слов каждого фразеологизма. Для этого использовался отдельный скрипт `lemmatr.py`, который работает следующим образом:

1. Скрипт извлекает таблицу с фраз-ми и запускает цикл по каждому из них, отбирая первые два слова
2. КАждое слово из пары прогоняется в режиме по **словоформе**
3. В результатах искомое слово подсвечивается оранжевым словом (стилевой класс 'result1'), а при наведении мыши на слова всплывает окошко с леммой
4. Селениум находит элемент с классом 'result1', потом методом **get** мы извлекаем атрибут "onmouseover" и в нем ищем первый параметр функции "popup"-- это и есть лемма
5. Далее пара лемм склеивается в строку и сохраняется в новой ячейке столбца "Лемма"

## Устройство основного скрипта (`final_parser.py`)

### 1. Импорты
Использованы библиотеки: `pandas`, `selenium`, `Levenshtein`, `re`, `time`, `os`, `traceback`

### 2. Конфигурация
Настройки: `HEADLESS`, `DELAY`, `SAVE_EVERY`, пути к файлам, список подкорпусов

### 3. Вспомогательные функции

| Функция | Назначение |
|---------|-----------|
| `set_lemma_mode` | Переключение режима поиска на поиск по лемме |
| `select_subcorpus` | Выбор одного из подкорпусов |
| `get_context` | Извлечение источника и текста расширенного контекста |
| `levenshtein_dist` | Расчёт расстояния Левенштейна (порог ≤5) |
| `have_common_bigram` | Поиск одинаковых пар букв в словах (для слов длиной >2) |
| `words_similar` | Комбинированная проверка похожести слов |
| `phrase_in_text` | Проверка наличия всех слов фразеологизма в тексте |
| `tokenize` | Разбиение фразеологизма на список слов |
| `find_and_click_pagination` | Переход на следующую страницу результатов |

### 4. Основная функция `main`

На вход получает две леммы, выполняет поиск, находит все блоки с упоминаниями словоформ этих лемм. Текст каждого блока сверяется с фразеологизмом: проверяется наличие каждого слова фразеологизма в тексте
с помощью `words_similar`. Если все слова найдены — запись добавляется в итоговую таблицу.

## Результаты
- Обработано **182 фразеологизма**
- **4 подкорпуса** (Пресса, Художественные, Нехудожественные, Устная речь)
- Итоговая таблица содержит **3255 записей** (включая пустые для подкорпусов без совпадений)

Статистика по подкорпусам (частотная таблица) вынесена на отдельный лист Excel.
